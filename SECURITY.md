# Security Policy

## Reporting a vulnerability

Please report security-sensitive issues privately to the repository owner rather than opening a public issue. Include a concise description, affected component, reproduction conditions, and possible impact.

## Sensitive configuration

Do not commit:

- SSH private keys;
- passwords or API tokens;
- private server hostnames or IP addresses;
- university account identifiers;
- tunnel commands containing sensitive infrastructure details;
- recordings that expose credentials or personal information.

## Robot safety

This repository is a research prototype, not a certified safety system. Test at low speed in a controlled area, keep an immediate stop method available, and do not operate near people, stairs, traffic, fragile objects, or uncontrolled obstacles.
